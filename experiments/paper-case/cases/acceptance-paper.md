# 案例 paper · 事先验收标准

> 运行前冻结，附 SHA-256（见 `frozen_hashes.json`）。评审用它判定 paper 案例是否达标。
> 本案例的判定重点是**「真实论文 + 真实数字」上，这套方法是不是真的站得住**。

## 一、合格线（缺任意一条即不合格）

| # | 检查项 | 合格条件 |
|---|---|---|
| PP1 | 四类前置条件齐全 | `compute` / `data scale` / `hyperparameters` / `hidden assumptions` 均至少 1 行 |
| PP2 | 定位必填 | 无空 `source_locator`；`confidence=absent` 的行带原因 |
| PP3 | 三分类合法 | 只能取 `paper-fact` / `inference` / `undetermined` |
| PP4 | paper-fact 必须有引文 | `paper-fact` 行的 `quote` 与 `locator` 均非空 |
| PP5 | 引文可程序化命中 | 在 `materials/source.txt` 内检索 `quote`，命中 ≥1 次且为连续片段 |
| PP6 | 结论唯一 | `verdict.md` 第 ① 节只给一个四选一结论词 + 理由 ≤2 句 |
| PP7 | 四段齐全 | 结论 / 确证 / 推断 / 遗留 四节都在，且顺序一致 |
| PP8 | 数值处置完整 | 超容差项全部有处置，未处置 = 0 |
| PP9 | 失败留痕 | `logs/run_log.md` 存在；失败/重试不得删除 |
| PP10 | 未改动 Skill | 运行所用 `skill/SKILL.md` 的 SHA-256 == `frozen_hashes.json` 里的锁定值 |
| PP11 | 预期行为对照 | `verdict.md` 有独立的「预期行为对照」小节，5 条预期行为**逐条**给出实际做法 |
| PP12 | 页码锚点 | 每条 `paper-fact` 的 `locator` 能落到 `materials/source.txt` 的某个 `=== PAGE n ===` 段内 |
| PP13 | 材料性质如实标注 | 引用材料时区分「真实论文」与「PDF 抽取文本」，不把抽取文本说成作者手写原文 |
| PP14 | 自检脚本原样跑 | `scripts/check_agreement.py` 退出码 0，`logs/agreement.json` 存在 |

## 二、paper 专属评分要点（5 条预期行为，逐条查）

| 预期行为 | 期望 | 不合格的样子 |
|---|---|---|
| ① 事实/推断分离 | 换算、推论、类比一律 `inference` 并写推理 | 把「LoRA 在 24GB 上能跑」写成 `paper-fact` |
| ② 数字可回算 / 论文自身不一致要写出来 | 发现摘要与正文、正文与脚注对不上时写进第 ④ 节 | 只引用一个数当"原文说的"，把不一致抹平 |
| ③ 换算给算式 | 落到「24 GB 单卡 + 7B」的换算有算式、参数来源、假设 | 只写一句定性判断，没有算式 |
| ④ 表格数字说清行列身份 | 引用表格数字时说明行列；不确定就降级 | 按压平序列的先后顺序猜一个行列 |
| ⑤ 可操作建议 | 给出要改什么、去哪查、本文不能保证什么 | 停在"论文很厉害" |

## 三、可判定的问题（Q）

> 评审按**报告里写的东西**回答，不按评审者自己重读的论文回答。

| # | 问题 | 判定 |
|---|---|---|
| Q1 | 报告给出的结论词是哪一个？ | 必须是四选一之一 |
| Q2 | 引用了论文里哪些**显存 / 参数量 / 吞吐**数字？各自定位到第几页？ | 逐条核对到 `source.txt` |
| Q3 | 报告把哪些内容算成了**换算 / 推断**？换算算式是什么？ | 必须能从报告里抄出算式 |
| Q4 | 报告有没有指出**论文自身**的数字不一致？有的话是哪一处？ | 有则加分；抹平则不合格 |
| Q5 | 报告有没有把**压平表格里的数字**安到某个行/列上？安对了没有？ | 安错且未降级 → 这就是本案例要抓的错 |
| Q6 | 报告给出的"在 24 GB 单卡上能不能跑"的结论，其**绝对量**是怎么闭合的？ | 只给相对降幅、不给绝对量 → 不合格 |

## 四、作者侧独立重算（作者做，不要求被测会话做）

| # | 检查项 | 要求 |
|---|---|---|
| PA1 | 逐条重算 | 报告引用的每个数字，从**论文原文**（不是从报告）重算一遍，给出值 / 页码 / 算式 / 结果 / 判定 |
| PA2 | 可一键复跑 | `python scripts/verify_paper_results.py` 从本目录运行，结尾 `status: passed`，退出码 0，仅标准库 |
| PA3 | 抓语义错误 | 至少找出一个**机械检查全绿但语义不成立**的点；若确实没有，如实写"未发现"并列出查过的维度 |
| PA4 | 模型输出与作者判断分离 | 账本里每条都标清楚"这是模型说的"还是"这是作者重算的" |
