# 案例 paper · 任务文本 —— 真实论文上的迁移判定

> **本案例验证"真实论文 + 真实数字"**：输入是一篇**公开发表的真实论文**（不是合成件），
> 论文里有可回算的数字，也有一个真实的迁移决策要做。
> 本文件在运行前冻结，冻结后哈希锁定（见 `frozen_hashes.json`）。

## 场景

你手上是一篇论文的 PDF 抽取文本。你要判断的是**这篇论文的方法能不能迁到你的场景**，
并且你的结论会被同事拿去用——所以**每一个数字都要能被回算**。

## 你的约束（运行前冻结）

| 维度 | 你的情况 |
|---|---|
| 算力 | 1 × RTX 4090（**24 GB 显存**）；可以租云卡补到 **≤ $200** |
| 模型规模 | 想微调一个 **7B 级别**的开源模型（GPT-2 medium 这个量级以下、7B 这个量级） |
| 数据 | 自有 **8,000 条**标注样本（英文）；公开数据集可自由下载 |
| 目标 | 只要**方法机制** + 「在我这儿能不能跑起来」的判定；**不要求**复现论文里的 GPT-3 175B 数字 |
| 判定口径 | 方法能不能迁，**不要求数字完全一致**；但**任何落到我场景的换算必须给出算式** |
| 期限 | 3 天内要出结论 |

## 材料（**注意：这是真实论文，但正文是 PDF 抽取文本**）

工作目录 `materials/` 下：

| 文件 | 是什么 |
|---|---|
| `source.txt` | 论文 PDF 的**逐页抽取文本**，页与页之间用 `=== PAGE n ===` 标记行分隔 |
| `source_pages.json` | 同一份文本按页切分的机器可读版本 |
| `source_manifest.json` | 来源 URL、版本、许可证、字节数、SHA-256、**抽取规则与已知限制** |

**材料性质声明（必须如实标注，不许含糊）**：

1. 论文是**真实的公开发表论文**（arXiv:2106.09685v2），**不是**构造件，
   引用它的数字时**可以**当作作者的事实来引用；
2. 但 `materials/source.txt` 是**从 PDF 抽取的文本**，不是作者手写的 Markdown/LaTeX 源文件；
   抽取的已知限制（小型大写标题、公式里的 `(cid:NN)` 私用区字形、**表格被压平为单元格序列、
   行/列身份不保留**）写在 `materials/source_manifest.json` 里，**引用前先读它**；
3. 引文必须逐字节等于 `materials/source.txt` 中的**连续片段**（**含换行符**）；
   原文跨行的地方要原样保留换行。

## 事先写明的预期行为（**这是评分依据，不是提示**）

在开始之前，下面这段是本案例**事先声明**的合理预期行为。运行后请在 `verdict.md` 里**逐条对照**说明你实际是怎么做的：

> **预期行为（事先声明）**
> 1. **事实与推断分开**：`paper-fact` 必须有原文定位与逐字引文；凡是你的推导（换算、推论、类比）
>    一律标 `inference` 并把推理过程写出来，**不许**写成论文的声明。
> 2. **数字要能被回算**：引用的每个数字都要给出原文**页码**定位；如果你在核对时发现**论文自身**
>    前后不一致（例如摘要与正文、正文与脚注对不上），要**如实写进第 ④ 节「遗留」**，
>    **不许**抹平、也不许只挑一个数当"原文说的"。
> 3. **换算必须给算式**：把论文的显存 / 可训练参数量 / 吞吐换算到你的「24 GB 单卡 + 7B」时，
>    必须写出**算式**、**参数的来源**和**你做的假设**；换算结论属于 `inference`，不是 `paper-fact`。
>    只写"LoRA 省显存，所以能跑"这种**没有算式**的话，视为没做到。
> 4. **表格数字要说清行列身份**：抽取文本里的表格是**压平**的单元格序列。
>    引用表格里的某个数字时，必须说明它对应**哪一行、哪一列**；
>    如果你无法确定，就降级为 `undetermined` 并写明原因，**不许**按出现顺序猜一个。
> 5. **给出可操作建议**：说明在 24 GB 单卡上落地这条路要改什么、去哪查，
>    以及**本文不能保证什么**（例如论文没覆盖的场景），而不是停在"论文很厉害"。

## 你要交付什么

| 文件 | 内容 |
|---|---|
| `preconditions.csv` | `id, category, value, unit, source_locator, confidence`；四类齐全；定位不到写 `confidence=absent` 并写明原因 |
| `claims.csv` | `claim_id, claim_text, classification, locator, quote, numeric_value, dependency_preconditions, reasoning, confidence`；三分类；`quote` 只给 `paper-fact` 填；`numeric_value` 只给 `paper-fact` 填 |
| `evidence_index.json` | `{id, kind, locator, quote, sha256}`，`quote` 必须是材料原文的连续片段，`sha256` 是被引文件的 SHA-256 |
| `verdict.md` | 四段（结论 / 确证 / 推断 / 遗留）+ **额外一节「预期行为对照」**，逐条对照上面 5 条预期行为，写明实际做法 |
| `logs/agreement.json` | 数值核对 + 处置 |

`verdict.md` 的四段顺序固定：

1. **Verdict** —— `transferable-as-is` / `transferable-with-changes` / `not-transferable` / `undetermined`
   四选一，外加 **≤2 句**理由；不许把两个结论词揉进一句话。
2. **What is established** —— `paper-fact` 结论，带定位。
3. **What I inferred** —— `inference` 结论，带推理；**明确标注不是论文说的**。
4. **What remains open** —— `undetermined` 结论 + `absent` 前置条件，各自写明「需要什么才能定 / 去哪找」。

## 硬性要求

1. **不要跑训练、不要下载数据集、不要装框架、不要联网**（除下面已列出的装配命令外）。
2. `quote` 必须是 `materials/source.txt` 的**单一连续片段**，逐字照抄（含换行），可被搜索命中。
3. `source_locator` 必填；定位不到写 `confidence=absent` + 原因。
4. `classification` 三选一；`paper-fact` 必须同时有 `locator` 与 `quote`；
   `inference` / `undetermined` 行的 `quote` 与 `numeric_value` **必须留空**，推理写进 `reasoning` 列。
5. 数值核对：相对误差超 1% 必须写处置（改 / 降级 / 写进第 ④ 节），**不许删行**。
6. **不许编造数字**——本文最重要的一条。
7. 遇到材料不足如实写，**合理澄清、降级或停止是正确结果**。
8. **失败、重试、人工修正全部留痕**（写进 `logs/run_log.md`）。

## 完成时

给出：结论词、三分类各多少条、降级条数、**5 条预期行为各做到了几条**、实际耗时、
最不确定的一点、以及**你核对时发现的论文自身不一致**（如果有）。**不要复述全部内容。**
