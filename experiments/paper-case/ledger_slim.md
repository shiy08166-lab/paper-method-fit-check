## 真问题：机械检查全绿，但语义不成立（错在论文自己身上）

论文第 5 页正文：`We also observe a 25% speedup`
同一页脚注 5：`32.5 tokens/s per V100 GPU`（全参微调）→ `43.1 tokens/s per V100 GPU`（LoRA）

**复算**：`43.1 / 32.5 − 1 = +32.62%`，不是 25%。
只有把 25% 读成「每 token 时间下降」（`1 − 32.5/43.1 = 24.59%`）才凑得上——**论文没说明口径**。

| 机械检查 | 结果 |
|---|---|
| 引文逐字命中原文 | ✅ 唯一命中 |
| `numeric_value` 与引文内数字一致（1% 内） | ✅ |
| `check_agreement.py` 标记数 | ✅ **0**（三次会话全部 0） |
| **结论「LoRA 训练快 25%」成立吗？** | ❌ **不成立**（论文自己的脚注给出 +32.6%） |

`check_agreement.py` 验的是「**引文里的数 == 你写的数**」，
**从不验**「这个数是不是从论文自己的别的数推出来的」。

**同一段第二处**：论文说「VRAM 降 2/3」「GPU memory by 3 times」，
而它自己的例子 `1.2TB → 350GB` 是 **3.43× / 70.83%**。

## 两个语义高危点（机械检查抓不到）

1. **表 1 的 `|Θ|` 行是 adapter 层的参数量**（表注原文：`"|Θ|" denotes the number of trainable
   parameters in adapter layers`），不是 LoRA 的。抽取文本把表压平后，这一行紧跟
   `Sequence Length`，极易被当成「LoRA 只需 0.5M 可训练参数」。
   真值（作者侧按 PDF 坐标重建）：`|Θ| = 0.5M / 11M / 11M`，分属 batch 32/16/1 三列。
2. **表 12（p.21）的行身份在抽取文本里丢了**：5 个行标签先连着出现，
   然后才是它们的值（`AdamW / 128 / 2 / 250,000 / Linear`）。按位置读会把 `128` 当成 Optimizer 的值。
   真值：Batch Size=128、# Epoch=2、Warmup Tokens=250,000、LR Schedule=Linear；
   Learning Rate：Fine-Tune=5.00E-06、LoRA=2.00E-04。

## 对方法本身的改进建议

1. **加第 7.5 步「复算论文自己的算术」**：对每个比率/降幅，找出它依赖的基线数重算，对不上写进「遗留」。
2. **否定性断言要挂证据**：凡「论文没给出 X」「未发现不一致」，必须在 evidence_index 里登记查过哪些位置，
   否则降级为 `undetermined`——**目前这类断言没有任何机械检查位**。
3. **相对降幅必须配绝对量**：`3×` 不能直接当「24GB 单卡能跑 7B」的依据。
4. **表格数字必须先确定行列身份**，确定不了就降级为 `undetermined`。
5. **把「按 PDF 坐标重建表格」进包**（或要求会话自己重建）。
6. **对前置条件的类别与置信度取值域给出机器可查的约束**
   （四类固定；`confidence ∈ {stated, inferred, absent}`）。

## 有 / 无 Skill 对照的诚实结论

同条件（同一篇论文、同一份冻结任务书、同一套材料字节、同一模型
`ccs-deepseek/deepseek-v4-pro`、同一套自检脚本），唯一变量是有没有 `SKILL.md`：

- **两轮的结论词相同**（`transferable-with-changes`）、**官方 checker 都是 0 标记退出码 0**、
  **都自己发现了那处口径不一致**、换算算式都可复算。
- **差别在台账**：前置条件 **21 条 vs 7 条**；有 Skill 那轮按四类
  （compute / data scale / hyperparameters / hidden assumptions）组织并用
  `stated / inferred / absent` 三档标注，**无 Skill 那轮自创了另一套类别名与 `confidence=high`**
  ——产物**不合契约**。
- **「发现论文自身不一致」不能归因于 Skill**：另一次有 Skill 的运行（换了模型路由、被上游 429 掐断前）
  **漏掉了**，还写下了一句**为假的否定性断言**。
  → 差别在**方法缺了一步**，不在「有没有 SKILL.md」。
- n=1、单一论文、单一平台：**不能做统计显著性宣称**，也不能说「Skill 更好/更差」。
